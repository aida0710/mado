Madoとして最初の正式なOSSリリースです。オブジェクトストレージの閲覧・編集に加え、Local User、OIDC SSO、RBAC、Service Account、操作監査、Dataset Lineageを一つの運用境界として提供します。

## 主な機能

- S3互換ストレージの一覧、preview、README・note・tag、download、移送見積もり
- Local UserとOIDC Authorization Code + PKCEによるSSO
- Viewer、Curator、Operator、AdminのRBACと接続単位capability
- HttpOnly server-side session、初回password変更、session失効
- Service Account keyによるOpenLineage ingestとnamespace制約
- Dataset Registry／Marquezを参照するLineage一覧・graph・手動登録
- 秘密値を除外し、成功した実変更だけを残す監査ログとdurable audit intent

## セキュリティと公開境界

Web UI、`/api/auth/`、`/api/internal/`はintranet向けです。外部公開用listenerは完全一致する`POST /api/openlineage/v1/lineage`だけを受け付けます。どちらもComposeからはloopbackへbindするため、利用者が用途別のTLS reverse proxyを用意してください。TLSなしでInternetへ公開しないでください。

productionでは`AUTH_MODE=disabled`を拒否します。OIDCを利用する場合はgroup allowlist、Role mapping、Secure cookieを設定し、独立したLocal break-glass Adminを維持してください。

既知の初期Admin passwordは配布しません。Webを起動する前にrelease bundleの手順でAdminをoffline bootstrapしてください。Internet向けOpenLineage processには専用の最小権限DB roleだけを渡し、OIDC secretやS3 credential暗号鍵は渡しません。Dataset Registry APIは別途必要です。

## Upgrade

既存DBは必ずbackupし、未適用migrationを番号順に確認してください。`028_drop_local_login_lock.sql`は旧APIが参照する列を削除するため、新API imageを先に起動してから適用します。`029_harden_lineage_and_bootstrap.sql`適用後は、専用DB roleへdeployment固有passwordを設定します。

公開前の最終確認では、release bundle内の手順、`docs/authentik.md`、`db/README.md`を参照してください。
