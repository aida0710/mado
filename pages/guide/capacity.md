# 容量の変化と移送の費用を確認する

接続内の **容量メトリクス** は、各バケットの容量とオブジェクト数を定期計測した結果です。バケット直下のディレクトリについても、容量上位50件の内訳を確認できます。

<Screenshot src="/screenshots/capacity.png" alt="容量メトリクスの推移グラフとディレクトリ別の内訳" caption="期間を切り替え、バケットやディレクトリごとの増減を見ます。" />

## バケットの推移と内訳を開く

Storageの接続内メニューから **容量メトリクス** を開きます。期間を選び、バケットの行を開くと内訳が表示されます。ディレクトリの行から、そのディレクトリの推移も確認できます。

**表示を更新** は保存済みの計測結果を読み直す操作です。S3の容量を改めて数える場合は **今すぐ全バケットを計測** を使います。計測の間隔と実行可否は[接続設定](../setup/connections.md)で管理します。

## いま開いているディレクトリの配下を数える

未集計ならファイル一覧の **配下を集計する**、集計済みなら **内訳** を押します。オブジェクト数、合計サイズ、サブディレクトリ別・拡張子別の内訳を確認できます。集計はS3の一覧取得を使い、本文はダウンロードしません。

<Screenshot src="/screenshots/scan.png" alt="ディレクトリ配下の件数、サイズ、拡張子の内訳" caption="完了した集計結果は、次に開いたときも確認できます。" />

## 移送先の費用と時間を比較する

集計後に **移送の見積もり** を開くと、別の接続へ移した場合の費用と時間が並びます。これは見積もりで、画面からファイルの移送は実行しません。

<Screenshot src="/screenshots/estimate.png" alt="Archive storageとAWS S3への移送見積もり" caption="この画面の金額・時間は、撮影用に設定したサンプル値です。" />

| 列 | 含むもの |
| --- | --- |
| 所要 | 帯域・オブジェクト数をもとにした楽観〜悲観の時間 |
| 初期 | 移動元のegress、取り出し、GET・PUTリクエストの費用 |
| 月額 | 移動先に保存し続けた場合の追加費用 |

接続設定の読み書き帯域を実測値に変えると、時間の見積もりに反映されます。無料枠や既存使用量との合算は考慮しないため、請求額そのものを示す数字ではありません。
