# 音声を見て、同じ位置で聴き比べる

音声ファイルを開くと、プレイヤー、波形、スペクトログラム、音声情報が表示されます。単体ファイルと、tar内の音声に対応しています。

<Screenshot src="/screenshots/audio-preview.png" alt="original.wavのプレイヤー、波形、スペクトログラム" caption="波形をクリックして再生位置を移動。サンプルレートやコーデックも確認できます。" />

## 波形とスペクトログラムを確認する

波形は時間ごとの音の振幅、スペクトログラムは周波数ごとの強さを表します。音の始まり、無音区間、処理前後の違いを探すときに使います。

解析結果はキャッシュされます。初回は解析の完了を待ちますが、直接再生と解析は別の経路です。波形の準備が終わる前でも、再生できる場合があります。

## 元の音声と処理後の音声を同期プレイヤーに追加する

1. ファイルの **⋯** メニューから **デッキに追加** を選びます。
2. 比べたい音声にも同じ操作をします。
3. 画面下部の **同期プレイヤー** で、再生位置を選んで一括再生します。

<Screenshot src="/screenshots/audio-deck.png" alt="original.wavとprocessed.wavを並べた同期プレイヤー" caption="複数トラックを同じ位置から再生。ミュートとソロで、聴く音声を切り替えます。" />

| 操作 | 動作 |
| --- | --- |
| 一括再生 / 一時停止 | 複数の音声をまとめて操作 |
| マスターシーク | 各トラックを同じ再生位置へ移動 |
| ミュート | そのトラックの音を消す |
| ソロ | 選んだトラックを聴く |
| L / R | ステレオ音声の左右チャンネルを選ぶ |
| 削除 | プレイヤーからトラックを外す |

プレイヤーから外しても、S3上のファイルは削除されません。

## 解析が表示されないときは接続設定を確認する

接続の **音声情報・波形の表示** が無効だと解析を行いません。**スペクトログラムの表示** も接続ごとに制限できます。

解析用の入力上限は、単体音声が2GiB、非圧縮tar内の音声が100MiBです。直接再生にはこの解析上限を適用しません。
