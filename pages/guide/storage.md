# バケットとファイルを探す

Storageで接続を選ぶと、その接続のバケットが並びます。よく使うバケットは星を押してお気に入りにできます。

<Screenshot src="/screenshots/storage-buckets.png" alt="Storageのバケット一覧とお気に入り" caption="バケット名を押して開く。別のストレージへはCONNECTIONから切り替えます。" />

## ディレクトリを辿り、パンくずで戻る

ディレクトリの行をクリックして下の階層へ進みます。上部のパンくずから親のディレクトリやバケット一覧へ戻れます。READMEがあれば、ファイル一覧の上に表示されます。

<Screenshot src="/screenshots/storage-directory.png" alt="samplesディレクトリのREADMEとファイル一覧" caption="README、ディレクトリ、ファイルを同じ画面で確認できます。" />

## 検索とタグで絞る

ファイル名の検索は、キーの**前方一致**です。下の階層も対象にするときは再帰検索を有効にします。一覧が続く場合は、下部のページ送りから次のページへ進めます。

タグが有効な環境では、バケット・ディレクトリ・ファイルにタグを付けられます。接続内のタグ検索は、ディレクトリを跨いで探したいときに使います。タグの定義と表示の有効化は **Settings → Features** で管理します。

## 取得時刻を見て、必要なら更新する

一覧とREADMEには取得時刻が表示されます。一覧の色は、S3から情報を取得してからの経過時間を示します。

| 経過時間 | 表示 |
| --- | --- |
| 1時間未満 | 色なし |
| 1〜3時間 | 緑 |
| 3〜6時間 | 黄 |
| 6〜12時間 | 橙 |
| 12〜24時間 | 赤 |
| 24時間以上 | 暗い赤 |

S3へファイルを追加した直後など、最新の一覧が必要なときは **↻** を押して取得し直してください。

## Web URLをコピーして共有する

ファイルの **⋯** メニューから、Web URL、S3 URL、ダウンロードを選べます。

| 操作 | 用途 |
| --- | --- |
| Web URLをコピー | madoのプレビューを同じ位置で開く |
| S3 URLをコピー | `s3://bucket/key` をスクリプトやメモで使う |
| ダウンロード | 元のファイルを手元に保存する |

Web URLを受け取った人にも、その接続へのアクセス権限とmadoへ届くネットワークが必要です。リンクをコピーしても、アクセス権限は増えません。
