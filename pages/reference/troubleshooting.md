# 困ったときは

Settingsの **About** でバージョンとコミットを確認できます。問題を報告するときは、操作した画面、ファイル形式、表示されたエラーを添えてください。

## 接続が一覧に出ない

管理者が **Settings → Connections** で接続を登録したか確認します。登録済みなら、ホワイトリストに自分が含まれているか管理者へ確認してください。許可されていない接続は、URLを直接開いても404になります。

## バケットやファイルを取得できない

接続のエンドポイント、リージョン、アクセスキー、path-style、ListObjectsの設定を確認します。接続先の認証情報には、バケット・オブジェクトの一覧を取得する権限が必要です。

S3互換実装で一覧応答が遅い場合は、走査の1ページ件数を1,000件から500件や250件へ減らしてください。loopbackやlink-localを指すエンドポイントは、接続先の制限によって拒否されます。

## S3に追加したファイルが見えない

一覧の **↻** を押して、S3から情報を取得し直します。一覧の帯の色と時刻は、その情報を取得してからの経過時間です。

## プレビューやダウンロードの操作がない

接続ごとの操作が無効になっている可能性があります。管理者が[接続の操作権限](../setup/connections.md#connection-capabilities)を確認してください。URLを直接開いても、API側で同じ制限を適用します。

## 動画が再生できない {#video-playback}

ブラウザが動画・音声のコーデックに対応しているか確認します。MP4という拡張子でも、内部のコーデックによって再生できない場合があります。

単体動画と非圧縮tar内の動画は部分取得に対応しています。圧縮tar内の動画には本文のプレビュー上限があるため、大きな動画の確認には非圧縮tarや単体ファイルを使います。

## tarの一覧が準備中のままに見える

非圧縮tarでは、ファイルの位置を索引に登録しながら続きを取得します。エントリが多いアーカイブは、準備に時間がかかる場合があります。

エラーが表示された場合は、その文言を確認してください。S3のオブジェクトが更新された場合は、再読み込みで新しい内容の索引を作り直します。

## 波形やスペクトログラムが表示されない

**音声情報・波形の表示** と **スペクトログラムの表示** が接続設定で有効か確認します。解析用入力の上限は、単体音声が2GiB、非圧縮tar内が100MiBです。大きな音声で直接再生だけが使える場合もあります。

## READMEを編集できない

CuratorまたはAdminの権限、接続の **READMEの編集**、接続先のS3書き込み権限を確認してください。READMEの読み込みが無効な接続では編集も使えません。

## Lineageにデータが出ない

Dataset Registryへの接続、データセットの登録、OpenLineageイベントの送信結果を確認します。グラフのnamespace、名前、バージョンが目的の対象と一致しているかも確認してください。

## ログインしていた画面に再ログインが出た

セッションが切れた場合は再ログインします。SSOの再ログインを新しいタブで済ませたら、元のタブに戻ってください。

## 管理者がログを確認する

```bash
docker compose -f compose.prod.yaml ps
docker compose -f compose.prod.yaml logs --tail 100 api-internal
docker compose -f compose.prod.yaml logs --tail 100 media-worker
```

開発環境では `compose.prod.yaml` を `compose.dev.yaml` に置き換えます。エラーの時刻と、問題の操作に関係するサービスを確認してください。
