# ストレージ接続を設定する

**Settings → Connections** から、S3互換ストレージを登録・編集できます。接続の管理にはAdminの権限が必要です。

<Screenshot src="/screenshots/connections.png" alt="Research storage、Archive storage、AWS S3を登録したConnections画面" caption="接続ごとに名前、用途、操作の許可を設定します。" />

## エンドポイントとS3の認証情報を登録する

**追加** を押し、名前、エンドポイント、リージョン、アクセスキーID、シークレットアクセスキーを入力します。登録済みの接続は、一覧の **編集** から変更できます。

<Screenshot src="/screenshots/connection-edit.png" alt="S3接続のエンドポイント、リージョン、認証情報を編集する画面" caption="画像の接続先はexample.comのサンプルです。実際の認証情報は載せていません。" />

| 項目 | 設定する内容 |
| --- | --- |
| 名前 | CONNECTIONメニューや一覧に出す表示名 |
| エンドポイント | S3互換APIのURL |
| リージョン | 接続先が要求するリージョン |
| アクセスキーID / シークレットアクセスキー | 接続先で発行したS3の認証情報 |
| path-style | 接続先のS3互換実装に合わせる |
| ListObjects | v1またはv2。接続先の対応に合わせる |

認証情報は保存時に暗号化します。既存の認証情報を変更しない場合は、編集フォームの案内に従って空欄のままにしてください。

## Storageで開くデフォルト接続を選ぶ

接続一覧の **デフォルトにする** を押すと、Storageタブを開いたときにその接続へ移動します。別の接続へはCONNECTIONメニューから切り替えられます。

## 接続を見せるユーザーを限定する

通常はログイン済みの全ユーザーに表示します。一部のユーザーだけに見せる場合は **ホワイトリスト** を選び、許可するユーザーを指定します。

許可されていないユーザーには接続が表示されず、URLを直接開いても404になります。接続を管理できるAdminは、設定を修正できるようアクセスできます。

## 許可する操作を接続ごとに絞る {#connection-capabilities}

<Screenshot src="/screenshots/connection-capabilities.png" alt="接続ごとのプレビュー、ダウンロード、README編集などを設定する画面" caption="一覧は見せつつ、本文取得や書き戻しを制限できます。" />

| 設定 | 無効にした場合 |
| --- | --- |
| バケット / オブジェクトの一覧 | この接続の一覧を開けない |
| ファイルのプレビュー | テキスト・画像・音声・動画を開けない |
| ファイルのダウンロード | ダウンロードの操作が表示されない |
| 圧縮ファイルを開く | tarなどの中身を開けない |
| 音声情報・波形の表示 | 音声解析を行わない |
| スペクトログラムの表示 | スペクトログラムを表示しない |
| READMEの読み込み / 編集 | READMEを読む・書く操作を制限 |

これらの制限はAPIでも確認します。Adminにも接続側の制限を適用するため、ボタンを隠すだけの設定ではありません。

## 走査・定期計測・見積もりの条件を設定する

**配下の走査を許可する** と **バケットのメトリクス集計を許可する** は別の設定です。定期計測を使う場合は有効化し、間隔を指定します。

走査の1ページ件数は100、250、500、1,000件から選べます。一覧応答が遅いS3互換実装では件数を減らしてください。

移送の見積もりには、接続ごとの読み書き帯域、並列数、プロバイダ、容量を使います。実測値が分かったら更新してください。
